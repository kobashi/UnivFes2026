# UnivFes2026 PC実習室アトラクション

PC実習室の iMac 40台を連動させ、Webカメラとサウンドを使った3つの展示を時間で切り替えてループ上演するシステムです。

- サーバ：Node.js 1台（外部パッケージ不要）
- 各iMac：Chrome をキオスク（全画面）で起動し、サーバのページを開くだけ
- 全台がサーバ時刻に同期し、同じタイムラインを各自で計算して描画します。通信が一瞬途切れても映像は揃ったまま動き続けます。

## 部屋の配置

```
───────────── 壁 ─────────────
········ 通路A ········          ← 壁を背に座り、列1の画面を見る
列1  [1][2]...[10]   画面 ↑      ← 壁側を向く
列2  [1][2]...[10]   画面 ↓      ← 列1と背中合わせ
········ 中央通路 ········       ← 向かい合う列2・列3の画面に挟まれた「光の廊下」
列3  [1][2]...[10]   画面 ↑      ← 列2と向かい合う
列4  [1][2]...[10]   画面 ↓      ← 列3と背中合わせ、壁側を向く
········ 通路C ········          ← 壁を背に座り、列4の画面を見る
───────────── 壁 ─────────────
```

各列の1番は、4列とも部屋の同じ側の端にあります。

## ネットワーク

| 役割 | IPアドレス |
|---|---|
| サーバ（教卓のiMac） | `192.168.112.70` |
| 列1 の 1〜10番 | `192.168.112.1` 〜 `.10` |
| 列2 の 1〜10番 | `192.168.112.11` 〜 `.20` |
| 列3 の 1〜10番 | `192.168.112.21` 〜 `.30` |
| 列4 の 1〜10番 | `192.168.112.31` 〜 `.40` |

- 座席（`列-番号`、例 `2-5`）はIPの末尾から自動で決まるので、生徒用iMacごとの設定は不要です。
- 教卓（`.70`）は座席の範囲外なので、展示の1台にはなりません。
- 配置やIPが変わった場合は `config.json` で調整します（下の「設定」を参照）。

## 展示（既定は各120秒でループ。切替時は3秒フェード）

| # | 演目 | 映像 | カメラ | サウンド |
|---|---|---|---|---|
| 1 | **光の回廊** `corridor` | 光のパルスが通路に沿って画面から画面へ走ります。中央通路では向かい合う列2・列3が同時に光るので、通路全体が光のトンネルになります。30秒ごとに動き（往復・すれ違い・虹の帯・高速チェイス）が変わり、20秒ごとに全台が同時にフラッシュします。 | ― | 光が通過したPCがペンタトニックの音を鳴らすので、音も部屋の中を走ります。フラッシュでは40台で1つの和音を鳴らします。 |
| 2 | **ミラー・リップル** `mirror` | Webカメラの映像をドット絵の鏡として映します。 | 画面の前で動くとその席から光の波紋が発生し、距離に応じた遅れで全PCに広がります。誰も動かない時はランダムな席から自動で波紋が出ます。 | 波紋が届いたPCが順に音を鳴らします。遠い席ほど音が小さくなります。 |
| 3 | **深海の大回遊** `migration` | 1列10台を1つの横長の海として、画面3枚分の大きさのクジラや魚の群れが泳いで渡ります。クラゲは常に漂っています。 | 前で動くと、その画面から泡が湧き上がります。 | クジラがいる画面から低音とクジラの声が鳴るので、音がクジラと一緒に移動します。 |

## 使い方

### 1. サーバ（教卓のiMac `192.168.112.70`）

教卓iMacは再起動で元に戻る設定のため、Node.js とこのリポジトリは消えない領域 `/Volumes/THAWSPACE` に置いています。

| もの | 場所 |
|---|---|
| Node.js（18 以上） | `/Volumes/THAWSPACE/node/bin` |
| このリポジトリ | `/Volumes/THAWSPACE/UnivFes2026`（フォルダ名が違う場合は読み替え） |

1. Finder で `/Volumes/THAWSPACE/UnivFes2026/scripts/start-server.command` をダブルクリックします。ターミナルから起動する場合は次を実行します。
   ```bash
   cd /Volumes/THAWSPACE/UnivFes2026
   ./scripts/start-server.command
   ```
   - `start-server.command` は `/Volumes/THAWSPACE/node/bin` の Node を自動で使うので、PATH を設定しなくても起動できます。
   - 「受信ネットワーク接続を許可しますか？」には「許可」を選びます。
2. ターミナルに次のように表示されれば起動しています。
   ```
     展示:     http://192.168.112.70:8080/
     管理画面: http://192.168.112.70:8080/admin
     各iMacで: curl -s http://192.168.112.70:8080/kiosk.sh | bash
   ```

「権限がありません」や「開発元を確認できません」で起動しない場合（ZIP で取得したときに起こります）は、一度だけ次を実行します。

```bash
cd /Volumes/THAWSPACE/UnivFes2026
chmod +x scripts/*.command scripts/*.sh
xattr -dr com.apple.quarantine .
```

#### ターミナルで `node` を使えるようにする（任意）

サーバの起動には不要ですが、ターミナルで `node` や `npm` を直接使いたい場合は PATH を通します。

```bash
echo 'export PATH="/Volumes/THAWSPACE/node/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
node -v
```

ホームフォルダが凍結されている場合、この設定は再起動で消えます。残したい場合は、凍結を解除した状態で設定してから凍結し直します。

#### リポジトリの更新

```bash
cd /Volumes/THAWSPACE/UnivFes2026
git pull
```

ZIP で取得した場合は、新しい ZIP を同じ場所に展開し直します（`config.json` を変更していたら控えておきます）。

ウィンドウを開いている間はサーバが動き、教卓iMacもスリープしません。サーバが落ちた場合は3秒後に自動で再起動します。止めるにはウィンドウを閉じます。

### 2. 生徒用iMac（40台）

各iMacで最初に1回だけ準備します。

1. Google Chrome が `/Applications` に入っていることを確認します。
2. **システム設定 › プライバシーとセキュリティ › カメラ** で Chrome を許可します。

展示を始めるときは、各iMacのターミナルで次を実行します。

```bash
curl -s http://192.168.112.70:8080/kiosk.sh | bash
```

- 起動スクリプトはサーバから配るので、各iMacにファイルを置く必要はありません。
- Chrome が全画面で起動します。カメラは自動で許可され、音もクリックなしで鳴ります。音量60%への設定とスリープ防止も同時に行います。
- 全画面を終了するには `⌘Q` を押します。
- `http://` でカメラを使うため、Chrome の `--unsafely-treat-insecure-origin-as-secure` を指定しています。通常の Chrome や Safari で開くと、カメラは使えず疑似映像になります。

#### 40台をまとめて起動/終了する（任意）

各iMacで **システム設定 › 一般 › 共有 › リモートログイン** を有効にし、展示用ユーザで画面にログインしておきます。そのうえで、教卓iMacのターミナルで実行します（`<ユーザ名>` は生徒用iMacのログインユーザ）。

```bash
SUBNET=192.168.112 USER_NAME=<ユーザ名> ./scripts/all-macs.sh start 192.168.112.70
SUBNET=192.168.112 USER_NAME=<ユーザ名> ./scripts/all-macs.sh stop
```

台ごとに `OK` / `NG` が表示されます。パスワードを聞かれずに接続できるよう、事前に SSH 鍵を登録しておく必要があります。

### 3. 管理画面 `http://192.168.112.70:8080/admin`

- 現在の演目と残り時間を表示します。演目へのジャンプ、固定（同じ演目を繰り返す）、固定の解除、最初からのループができます。
- ミュート・音量・**座席番号表示**（全画面に `2-5` などを大きく表示し、設置時の確認に使います）・全台リロードができます。
- 40台の接続状況を配置図で表示します。緑は正常、黄は音声・カメラ・fps のいずれかに問題あり、赤は未接続です。
- `adminToken` を設定した場合は `/admin?token=...` で開きます。

### 4. シミュレータ `http://192.168.112.70:8080/sim`

40台分の画面を俯瞰図どおりに1ページで再現するので、実機がなくても演出を確認できます。画面をクリックするとその席で動きを検出したことになり、波紋が出ます。「音を聴く座席」を選ぶと、その席の音を聴けます。

### 5. 本番前の通し確認

1. **全台の接続**：管理画面で 40 / 40 台オンラインになり、全台が緑になっているか確認します。黄色の台はカメラの許可か音声に問題があります。
2. **座席の位置**：「座席番号表示」を押し、各画面の番号が実際の位置と合っているか見て回ります（例：`192.168.112.3` の画面に `1-3`）。確認後にもう一度押して消します。
3. **3つの演目**：各演目の「ここへ」を押し、通路を歩いて確かめます。
   - 光の回廊：光と音が列に沿って流れるか
   - ミラー・リップル：カメラの前で手を振ると、波紋が周りに広がるか
   - 深海の大回遊：クジラが画面をまたいで泳ぎ、音がクジラと一緒に動くか
4. **音量**：来場者がいる状態を想定し、管理画面のスライダーで調整します。
5. **ループ再開**：最後に「最初からループ」を押して本番の状態に戻します。

### 困ったとき

| 症状 | 対処 |
|---|---|
| 画面に「座席に割り当てられていません」と出る | そのiMacのIPが `.1〜.40` 以外になっています。IPを確認するか、`config.json` の `seatOverrides` で座席を指定します |
| 管理画面で赤（未接続） | その台で `curl -s http://192.168.112.70:8080/kiosk.sh \| bash` を再実行します |
| 黄色で 📷 が出ない | システム設定でChromeのカメラを許可し、キオスクを再起動します |
| 黄色で 🔇 | 管理画面の「全台リロード」を試します。直らなければキオスクを再起動します |
| 映像がカクつく（fpsが低い） | `config.json` の `renderScale` を `0.5` にしてサーバを再起動し、「全台リロード」を押します |
| 全台の様子がおかしい | サーバのウィンドウでエラーを確認し、管理画面の「全台リロード」を押します |

### 動作確認用URLパラメータ

- `?seat=2-5`：座席を指定します
- `?nocam`：カメラを使いません
- `?mute`：音を出しません

## 設定 `config.json`

| キー | 説明 |
|---|---|
| `port` | 待受ポート（環境変数 `PORT` でも可） |
| `ipMapping.octetStart` | 列1の1番になるIP末尾（現在 `1`） |
| `layout.rowReverse` | 列ごとに番号の向きを反転する（現在は全列 `false`） |
| `seatOverrides` | IP → 座席 の個別指定。例 `{ "192.168.112.57": "3-7" }` |
| `scenes` | 上演順と秒数。同じ演目を複数回並べることもできます |
| `transition` | 切替フェードの秒数 |
| `volume` | 初期音量 0〜1 |
| `renderScale` | 描画解像度の倍率。重い場合は `0.5` にします |
| `motionThreshold` | 動き検出の感度。小さいほど反応しやすくなります |
| `idleRippleSec` | ミラー上演中、この秒数だれも動かなければ自動で波紋を出します |
| `adminToken` | 管理操作のパスワード（空なら不要） |

`config.json` を変更したら、サーバのウィンドウを閉じて `start-server.command` を開き直し、管理画面で「全台リロード」を押します。

## 開発

```
server/server.js        制御サーバ（HTTP + Server-Sent Events）
public/index.html       各iMacの表示ページ → js/app.js
public/sim.html         40台シミュレータ → js/sim.js
public/admin.html       管理画面
public/js/layout.js     座席と部屋の物理配置、IP→座席の変換
public/js/schedule.js   演目タイムライン
public/js/runtime.js    1台分の演目切替・フェード・オーバーレイ
public/js/scenes/       演目（新しい演目はここに追加し index.js に登録）
scripts/                macOS 用キオスク起動スクリプト
```

演目は `frame(ctx, w, h, t, dt, {now, info})` を持つクラスです。`env.seat.x` と `screenToWorldX` / `worldToScreenU` を使い、部屋全体で共通の座標で描きます。こうすると、複数の画面にまたがる絵が自然につながります。

```bash
npm test
```
